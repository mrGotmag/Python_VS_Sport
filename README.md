# 🏆 Python vs Спорт

Платформа для проведения олимпиад по программированию с элементами физкультуры (МИВлГУ).

## 🚀 Быстрый старт (Windows)
1. Запустите `install.bat` (он сам скачает Python, Git, зависимости и запустит сервер).
2. Откройте браузер: `http://localhost:8000`.

## 🐧 Linux / macOS
1. `chmod +x install.sh`
2. `./install.sh`

---

## 🔑 Роли и доступы

### 1. Администратор
- **Вход:** Первый запуск перенаправляет на `/setup` для создания пароля админа.
- **Возможности:** Управление фазами, задачами, экспорт CSV. Видит полный рейтинг (Код + Спорт + Итоговое место).

### 2. Участники (Регистрация)
- Заходят на `/register`, вводят **Имя** и **Email**.
- Система **автоматически распределяет** их в команды по 5 человек.
- Участник получает **персональный 4-значный код** для входа. Вход по этому коду на главной странице.
- Если команда набрала 5 человек (или админ запустил принудительно), таймер стартует.

### 3. Судья (Спорт)
- Админ во вкладке «Судьи» создает судью и получает его код.
- Судья заходит на `/staff`, вводит этот код.
- **Возможности:** Ввод **количества подходов** для каждой спортивной дисциплины (без баллов). Может менять правило (Больше/Меньше = лучше).

---

## ⚙️ Как работает система (Под капотом)

### Формирование команд
Участники регистрируются и автоматически падают в первую незаполненную команду (до 5 человек). Админ может принудительно запустить неполную команду из монитора админки.

### Проверка кода
- Код запускается в изолированном процессе (Sandbox).
- Заблокированы опасные библиотеки (`os`, `sys`), функции (`open`, `eval`, `exec`).
- Замеряется время (`time_ms`) и память (`memory_mb`).

### Олимпийская система подсчёта мест
Итоговое место определяется по сумме мест в двух дисциплинах:
1. **Место по Python:** по убыванию баллов, затем по времени/памяти.
2. **Место по Спорту:** для каждой спорт-фазы считаются места (с учетом "больше/меньше"). Затем места по всем фазам суммируются (кто стабильнее — тот выше).
3. **Итог:** `место_питон + место_спорт`. Кто набрал меньшую сумму — тот победил. (Защита от читинга: нельзя занять 1-е место, завалив одну из дисциплин).

## 📊 Экспорт CSV
Кнопка «ЭКСПОРТ CSV» в админке выгружает протокол:
- Итоговое место, Место по коду, Место по спорту.
- Баллы по коду, Сумма подходов.
- Детализация по каждому спортивному упражнению.
