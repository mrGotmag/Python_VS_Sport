# Система проведения олимпиад «Python vs Спорт»

Этот файл содержит полное описание проекта, инструкции по установке, настройке и использованию всех функций системы.

---

## 📖 О проекте

**«Python vs Спорт»** — это полноценная веб-платформа для проведения олимпиад и соревнований по программированию среди школьников и студентов. Система позволяет участникам решать задачи в режиме реального времени, а организаторам — управлять ходом соревнования, настраивать таймеры и проверять решения.

В основе лежит автоматический проверяющий модуль (`orcestrator`), который запускает код участника в изолированной среде и сравнивает результат с эталоном.

### ✨ Основные возможности:
- **Для участников:** Личный кабинет с редактором кода (CodeMirror), автоматическая проверка решений, красивый вывод результатов (OK/FAIL), сохранение черновиков в браузере, обратный отсчет времени.
- **Для организаторов (Админов):** Создание/редактирование/удаление задач и команд, гибкое управление таймером (старт, пауза, стоп), индивидуальные таймеры для каждой команды, живой рейтинг.
- **Безопасность:** Хеширование паролей (bcrypt), авторизация через HttpOnly Cookies (JWT), защита от спама при регистрации.
- **Синхронизация:** Обновление данных на экранах участников в реальном времени через WebSocket (без перезагрузки страницы).

## ⚙️ Технологический стек

## 🚀 Установка и запуск

### Вариант 1: Автоматическая установка (Windows)
1. Скачайте файл `install.bat` из корня репозитория.
2. Запустите его двойным кликом.
3. Скрипт автоматически:
   - Проверит наличие Python и Git.
   - Склонирует репозиторий (или обновит существующий).
   - Создаст виртуальное окружение `.venv` и установит зависимости.
   - Создаст файл `.env`.
   - Запустит сервер и откроет браузер с адресом `http://localhost:8000`.

### Вариант 2: Автоматическая установка (Linux/macOS)
```bash
git clone https://github.com/mrGotmag/Python_VS_Sport.git
cd Python_VS_Sport
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
cd web
python run.py
```

### Вариант 3: Ручной запуск (если уже установлено)
```bash
# Активация виртуального окружения
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate

cd web
python run.py
```
*Сервер запустится на `http://0.0.0.0:8000` (доступен по локальной сети).*

## 👑 Первый запуск (Настройка Админа)

При первом запуске база данных пуста, поэтому система автоматически перенаправит вас на страницу **первичной настройки**.

1. Откройте `http://localhost:8000`.
2. Вы попадете на страницу **`/setup`**.
3. Придумайте и введите **пароль Администратора**.
4. Нажмите «СОЗДАТЬ». 
5. Теперь вы можете войти в систему под этим паролем.

---

## 🎮 Как пользоваться системой

### 🔐 Вход в систему
На главной странице есть только одно поле — **«Введите пароль»**. 
- Если вы введете **пароль Админа**, система перекинет вас в **Панель управления** (`/admin`).
- Если вы введете **пароль Команды**, система перекинет вас в **Личный кабинет** (`/team`).

---

### 💻 Интерфейс участника (Команды)
Каждая команда получает свой уникальный пароль (генерируется автоматически).
1. **Список задач:** Слева находится список доступных задач с указанием максимального балла.
2. **Решение:** Выберите задачу, прочитайте условие, напишите код в редакторе и нажмите **«ОТПРАВИТЬ РЕШЕНИЕ»**.
3. **Результат:** Под редактором появится отчет от чекера: какие тесты пройдены (`[ OK ]`), а какие нет (`[FAIL]`), с указанием ошибок.
4. **Таймер:** В шапке сайта отображается обратный отсчет. Пока олимпиада не запущена админом или стоит на паузе, задачи заблокированы, а индикатор горит красным (`OFFLINE`).
5. **Черновики:** Введенный код автоматически сохраняется в браузере. Если вы случайно закроете вкладку, при возвращении код останется на месте.

---

### 🛠 Интерфейс Администратора
Панель управления разделена на две вкладки: **Рейтинг** и **Задачи**.

#### 1. Управление соревнованием (Таймер)
- **Кнопка «▶ СТАРТ»**: Запускает соревнование для всех команд. С этого момента у участников начинается отсчет времени.
- **Кнопка «⏸ ПАУЗА»**: Останавливает время. Участники не могут отправлять решения, пока вы не снимите паузу. 
- **Ползунок длительности**: Позволяет изменить общее время олимпиады (от 1 минуты до 4 часов). *Изменять время можно только когда таймер стоит на паузе.*
- **Индивидуальное управление:** В таблице рейтинга можно поставить на паузу, возобновить или принудительно завершить соревнование для конкретной команды.

#### 2. Управление командами
- В таблице рейтинга отображаются все команды, их баллы и оставшееся время.
- Кнопка **«+ КОМАНДА»** позволяет создать новую команду вручную (система выдаст пароль для входа).
- Кнопка **«🗑»** удаляет команду и все её решения из базы.

#### 3. Управление задачами
- Вкладка **«ЗАДАЧИ»** показывает список всех задач.
- Кнопка **«+ ДОБАВИТЬ ЗАДАЧУ»** открывает модальное окно, где можно вставить текст задачи (Markdown) и JSON с тестами.
- Кнопка **«Редактировать»** позволяет изменить условие и тесты уже существующей задачи.
- *Все изменения задач автоматически сохраняются в файлы в папке `orcestrator/tasks/{ID}` и мгновенно синхронизируются с участниками.*

## 📝 Формат добавления задач (через API или файлы)

Если вы хотите добавить задачу вручную (без админки), создайте папку `orcestrator/tasks/{ID}` (где ID — число) и положите туда два файла:

**task.txt** (условие в формате Markdown):
```text
# Задача 1. Сумма чисел
Условие: Считайте два числа и выведите их сумму.
Формат ввода: Два числа через пробел.
Формат вывода: Одно число.
Пример:
Ввод: 3 5
Вывод: 8
```

**tests.json** (тесты для чекера):
```json
{
  "task": {
    "title": "Сумма чисел",
    "time_limit_sec": 2.0
  },
  "tests": [
    {
      "id": 1,
      "input": "3 5\n",
      "expected_output": "8\n",
      "points": 50
    },
    {
      "id": 2,
      "input": "10 -2\n",
      "expected_output": "8\n",
      "points": 50
    }
  ]
}
```

## 🔒 Безопасность
- Пароли организаций и админов не хранятся в открытом виде (используется `bcrypt`).
- Доступ к API защищен JWT-токенами, которые передаются в защищенных `HttpOnly` Cookies (защита от XSS).
- Запуск кода участника изолирован от веб-сервера (через `subprocess` с ограничением времени выполнения).

## 🆘 Частые проблемы

**1. Страница входа выдает ошибку 401 Unauthorized.**
- Очистите кэш браузера или файлы cookie. Возможно, вы сменили пароль администратора или базу данных.

**2. Участник видит надпись «ОЖИДАНИЕ СТАРТА» и не может открыть задачи.**
- Зайдите в админку (`/admin`) и нажмите кнопку **«▶ СТАРТ»**.

**3. Не отображаются задачи у команды.**
- Убедитесь, что папки в `orcestrator/tasks` содержат файлы `task.txt` и `tests.json`. Перезапустите сервер, чтобы прошла синхронизация.

**4. Ошибка `sqlite3.OperationalError: no such table`.**
- Удалите файл `contest_web.db` (он лежит в папке `web`) и перезапустите сервер. База данных создастся заново.
