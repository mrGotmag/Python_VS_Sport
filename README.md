# 🏆 Python vs Спорт

Добро пожаловать в **Python vs Спорт** — веб-платформу для проведения соревнований по программированию, хакатонов и олимпиад с автоматической проверкой кода. 

Проект создан с упором на простоту развертывания и современный UX: участникам доступен продвинутый редактор кода с подсветкой и подсказками, живой таймер, а также виртуальная песочница для тестирования решений до отправки. Вам не нужно быть системным администратором, чтобы запустить платформу — достаточно одного клика!

---

## 🚀 Быстрый старт (Windows)

Мы подготовили полностью автоматический скрипт установки, который сделает всё за вас.

1. Скачайте папку с проектом (или склонируйте репозиторий).
2. Найдите файл **`install.bat`** и запустите его двойным кликом.
3. Сядьте поудобнее и наблюдайте. Скрипт:
   * Проверит наличие **Python 3.12** и **Git**. Если их нет — автоматически скачает и установит в тихом режиме.
   * Скачает актуальные файлы проекта.
   * Создаст виртуальное окружение (`.venv`) и установит все зависимости.
   * Сгенерирует надежный `SECRET_KEY` и создаст файл конфигурации `.env`.
   * Откроет порт `8000` в брандмауэре Windows.
   * Запустит локальный сервер, выведет IP-адреса для подключения и откроет сайт в вашем браузере.

> **Важно:** При первом запуске установка Python и Git может занять несколько минут. Пожалуйста, не закрывайте черное окно консоли во время установки!

## 🐧 Установка на Linux / macOS

Для пользователей Unix-подобных систем предусмотрен аналогичный скрипт на Bash.

1. Откройте терминал и перейдите в папку с проектом.
2. Дайте скрипту права на выполнение:
   ```bash
   chmod +x install.sh
   ```
3. Запустите его:
   ```bash
   ./install.sh
   ```

## 🌐 Как подключиться с другого устройства (Телефон, Планшет, Другой ПК)

По умолчанию сервер доступен только на том компьютере, где он запущен (`http://localhost:8000`). Чтобы зайти на сайт с телефона или другого ноутбука:

1. Убедитесь, что оба устройства подключены к **одной и той же Wi-Fi сети**.
2. При запуске сервер выведет в консоль список доступных IP-адресов. Найдите тот, который относится к вашей локальной сети (обычно начинается на `192.168.x.x` или `10.x.x.x`).
3. Введите этот адрес (например, `http://192.168.1.55:8000`) в браузере на вашем телефоне.
4. **Если не работает:**
   * Проверьте, что брандмауэр не блокирует порт `8000` (скрипт пытается открыть его автоматически, но иногда требуются права Администратора).
   * Убедитесь, что ваш Wi-Fi роутер не использует «Изоляцию клиентов» (Client Isolation). В таком случае используйте «Мобильный хот-спот» на Windows для создания прямой связи.

## 📁 Архитектура и структура проекта

Проект разделен на два основных логических блока: **`web`** (пользовательский интерфейс и API) и **`orcestrator`** (фоновая логика проверки кода).

```text
Python_VS_Sport/
├── .env                     # Единый файл конфигурации (создается автоматически)
├── .env.example             # Шаблон конфигурации
├── .venv/                   # Виртуальное окружение Python
│
├── orcestrator/             # ОРКЕСТРАТОР (Бэкенд-логика)
│   ├── logs/                # Логи работы оркестратора и проверок
│   ├── tasks/               # Папка с файлами задач (тесты, условия)
│   ├── batch_runner.py      # Запуск задач пачками
│   ├── checker.py           # Ядро проверки: компиляция и запуск кода
│   ├── code_reader.py       # Модуль чтения и парсинга присланного кода
│   ├── config.py            # Загрузка конфигурации
│   ├── logger_setup.py      # Настройка логирования и авто-очистка логов
│   ├── main.py              # Точка входа для запуска оркестратора
│   ├── pool.py              # Пул воркеров (многопоточность)
│   └── reporter.py          # Генерация отчетов по итогам проверок
│
├── web/                     # ВЕБ-ПРИЛОЖЕНИЕ (Фронтенд + API)
│   ├── app/                 # Исходный код FastAPI (роуты, шаблоны, модели)
│   ├── contest_web.db       # База данных SQLite
│   └── run.py               # Умный запуск сервера (определение IP, порты)
│
├── install.bat              # Скрипт автоустановки для Windows
├── install.sh               # Скрипт автоустановки для Linux/macOS
├── requirements.txt         # Зависимости Python
└── README.md                # Документация проекта
```

## ⚙️ Как работает программа (Под капотом)

Система разделена на два независимых процесса: **Веб-сервер (Web)** и **Оркестратор (Orchestrator)**.

1. **Взаимодействие с пользователем (Web-часть):** Веб-сервер на базе **FastAPI** обрабатывает запросы. Студент авторизуется (пароли хешируются, сессии защищены `JWT-токенами`). Все данные сохраняются в локальной базе **SQLite**.
2. **Очередь и запуск:** Когда пользователь отправляет код, веб-сервер создает запись в БД со статусом «В очереди». Оркестратор (модуль `pool.py`) забирает задачу в работу, чтобы не нагружать веб-сервер.
3. **Проверка кода:** `code_reader.py` читает файл. `checker.py` запускает код в изолированной среде (с ограничениями по времени и памяти). `reporter.py` сравнивает вывод программы с правильным ответом и формирует вердикт (`OK`, `Wrong Answer`, `Time Limit`).
4. **Возврат результата:** Оркестратор обновляет статус в БД, а веб-сервер моментально отображает результат пользователю через WebSocket.

## 🖥️ Руководство пользователя (UX)

### 👨‍🎓 Для студента (Участника)
1. **Вход в систему:** Откройте сайт и авторизуйтесь.
2. **Выбор задачи:** На главной странице отобразится список задач. Рядом видны статусы, ограничения и живой таймер.
3. **Редактор кода:** Встроенный CodeMirror поддерживает подсветку синтаксиса Python, автодополнение (подсказки при вводе) и авто-закрытие скобок.
4. **Виртуальный запуск (Playground):** На вкладке «ТЕСТИРОВАНИЕ» можно ввести свои входные данные и проверить работу программы *до* отправки на сервер. Это помогает быстрее находить логические ошибки.
5. **Отправка и вердикт:** Нажмите «Отправить». Статус обновится через несколько секунд:
   * 🟢 **OK (Принято):** Все тесты пройдены.
   * 🔴 **Wrong Answer (WA):** Неверный ответ.
   * 🟡 **Time Limit (TL):** Программа работает слишком долго.
   * 🟠 **Runtime Error (RE):** Программа упала с ошибкой.
6. **Автосохранение:** Черновики ваших решений автоматически сохраняются в браузере (`localStorage`). Если вы случайно закроете вкладку, код не пропадет.

### 👨‍🏫 Для администратора (Преподавателя)
* **Добавление задачи:** Создайте папку в `orcestrator/tasks/`, положите туда условие, а также файлы `input.txt` и `output.txt`.
* **Управление таймером:** В панели администратора можно запустить глобальный таймер, поставить его на паузу или завершить соревнование принудительно. У студентов изменения отобразятся моментально.
* **Мониторинг:** Все шаги проверки сохраняются в `orcestrator/logs/`. Логи старше 24 часов автоматически удаляются при перезапуске сервера.

## 🛠 Ручной запуск (для разработчиков)

Если вы хотите запустить сервер без автоматического установщика:

1. Активируйте виртуальное окружение:
   * **Windows:** `.venv\Scripts\activate`
   * **Linux/macOS:** `source .venv/bin/activate`
2. Перейдите в папку веб-приложения:
   ```bash
   cd web
   ```
3. Запустите сервер:
   ```bash
   python run.py
   ```
Сервер будет автоматически перезагружаться при изменении файлов (режим `reload=True`).

## ❓ Частые проблемы (FAQ)

**1. Ошибка `Permission denied` при установке.**
Это происходит, если вы запускаете `install.bat` из системной папки. Скрипт автоматически переносит установку на Рабочий стол, но убедитесь, что вы запускаете его из обычной папки.

**2. Консоль закрывается моментально при запуске `install.bat`.**
Откройте командную строку (`cmd`) вручную, перейдите в папку с проектом и запустите `install.bat`. Так вы сможете увидеть текст ошибки.

**3. С телефона не открывается сайт, хотя IP-адрес введен верно.**
Скорее всего, брандмауэр Windows блокирует подключения. Запустите `install.bat` от имени Администратора, чтобы скрипт создал правило для порта 8000.

**4. Сервер пишет `[СЕТЬ] Не удалось открыть порт`.**
Запустите терминал (или `install.bat`) от имени Администратора. Windows требует повышенных привилегий для изменения правил брандмауэра.

**5. Код выдает `Wrong Answer`, хотя локально всё работало.**
Проверьте, не выводите ли вы лишние подсказки в `input()` (например, `input("Введите число: ")`). Проверяющая система сравнивает **весь** вывод программы с эталоном.
