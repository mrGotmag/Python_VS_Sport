# 🏆 Python vs Спорт

Платформа для проведения олимпиад по программированию с элементами физкультуры (МИВлГУ).

## 🚀 Быстрый старт (Windows)
1. Запустите **`install.bat`** (он скачает Python, Git, зависимости и настроит окружение).
2. В конце установки автоматически запустится **`start_server.bat`**.
3. Согласитесь на запрос прав Администратора (UAC) — это нужно, чтобы открыть порт `8000` в брандмауэре и разрешить подключение с телефонов.
4. Откройте браузер: `http://localhost:8000`.

> **Удаление:** Чтобы полностью удалить проект и очистить правила брандмауэра, запустите `uninstall.bat`.

## 🐧 Быстрый старт (Linux / macOS)
1. Дайте права на запуск: `chmod +x install.sh`
2. Запустите установщик: `./install.sh`
3. Для запуска сервера используйте: `./start_server.sh` (запросит пароль `sudo` для сетевых портов).
4. Для удаления: `chmod +x uninstall.sh` и `./uninstall.sh`.

## 🔑 Роли и доступы

### 1. Администратор
- **Вход:** Первый запуск перенаправляет на `/setup` для создания пароля админа.
- **Возможности:** 
  - Управление фазами (задачи и спорт). Настройка правила для спорта (Больше/Меньше = лучше).
  - Создание команд и добавление в них участников вручную (система генерирует коды).
  - Принудительный запуск неполных команд.
  - Просмотр **личного** рейтинга учеников (Код + Спорт + Итоговое место).
  - Экспорт полного CSV-протокола.

### 2. Участники (Регистрация)
- Заходят на `/register`, вводят **Имя** и **Email**.
- Система **автоматически распределяет** их в команды по 5 человек.
- Участник получает **персональный код доступа** (**8** символов) для входа.
- **Таймер:** Запускается только тогда, когда первый участник из команды заходит на сайт (или когда админ запустит команду принудительно). У всех 5 членов команды таймер синхронизирован.
- **Баллы:** Каждый участник решает задачи и получает баллы **лично за себя**.

### 3. Судья (Спорт)
- Админ во вкладке «Судьи» создает судью и получает его 4-значный код.
- Судья заходит на `/staff` (интерфейс адаптирован под телефоны).
- **Возможности:** 
  - Выбор дисциплины и смена правила (Больше/Меньше = лучше).
  - Поиск участника по имени или команде.
  - Ввод **количества подходов** лично каждому ученику.

## ⚙️ Как работает система (Под капотом)

### Формирование команд и таймеры
Участники регистрируются и автоматически падают в первую незаполненную команду (до 5 человек). Время команды не идет, пока хотя бы один из её участников не зайдет на сайт (защита от фальстарта).

### Проверка кода
- Код запускается в изолированном процессе (Sandbox).
- Заблокированы опасные библиотеки (`os`, `sys`), функции (`open`, `eval`, `exec`).
- Замеряется точное время (`time_ms`) и пиковая память (`memory_mb`).
- Участнику выдается понятный вердикт: `OK`, `WA` (неверный ответ), `TL` (превышено время), `RE` (ошибка выполнения), `CE` (синтаксическая ошибка).

### Олимпийская система подсчёта мест (Личный зачет)
Каждый ученик соревнуется сам за себя. Итоговое место определяется по сумме мест в двух дисциплинах:
1. **Место по Python:** Считается по убыванию баллов личного ученика, затем по времени/памяти.
2. **Место по Спорту:** Для каждой спорт-фазы считаются места среди учеников (с учетом "больше/меньше"). Затем места по всем фазам суммируются (кто стабильнее — тот выше).
3. **Итог:** `место_питон + место_спорт`. Кто набрал меньшую сумму — тот победил. (Защита от читинга: нельзя занять 1-е место, завалив одну из дисциплин).

## 🌐 Доступ по локальной сети (для телефонов)
Если вы запускаете сервер на ПК, а участники/судьи заходят с телефонов:
1. Убедитесь, что все устройства в одной Wi-Fi сети.
2. В консоли при запуске сервера найдите адрес вида `http://192.168.X.X:8000`.
3. Введите этот адрес в браузере телефона.
4. *Если не работает:* проверьте, что `start_server.bat` запущен от имени Администратора (чтобы брандмауэр пропускал подключения).

## 📊 Экспорт CSV
Кнопка «ЭКСПОРТ CSV» в админке выгружает готовый протокол для Excel:
- **Итоговое место**, Имя ученика, Название команды.
- Место по коду, Баллы по коду.
- Место по спорту, Сумма подходов.
- Детализация подходов по каждому спортивному упражнению.
*(Файл выгружается в кодировке UTF-8 с BOM, разделитель `;` — Excel открывает без «кракозябр»).*
