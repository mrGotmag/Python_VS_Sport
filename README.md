# Python vs Спорт — Олимпиадная система

Веб-платформа для проведения соревнований по программированию с автоматической проверкой кода (на базе `orchestrator`).

## Установка (Windows)

1. Скачайте файл `install.bat`.
2. Запустите его двойным кликом.

## Установка (Linux/macOS)

1. Скачайте файл `install.sh`.
2. Дайте ему права на выполнение: `chmod +x install.sh`
3. Запустите: `./install.sh`

## Запуск

**Windows:**
```powershell
cd Python_VS_Sport\web
..\.venv\Scripts\activate
python run.py
