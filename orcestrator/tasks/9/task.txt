Задача 4: Длина повторяющейся последовательности
Ограничение по времени: 1 секунда

Числа Фибоначчи формируются по следующей формуле: ai = ai-1 + ai-2, a1 = a2 = 1 (i = 1, 2, 3, ..., n, где n — количество чисел). Однако с увеличением n происходит резкое возрастание значений чисел. Для избежания резкого возрастания будем формировать числа по следующей формуле: ai = (ai-1 + ai-2) mod m, где mod — операция вычисления остатка от деления, m — целое число. Например, для m = 4 получим следующую последовательность чисел: 1, 1, 2, 3, 1, 0, 1, 1, 2, 3, .... Здесь наблюдается повторяющаяся последовательность длины 6. Для заданного числа m необходимо найти длину повторяющейся последовательности.

Формат входных данных
В первой строке вводится целое число m (2 ≤ m ≤ 30) для формирования чисел Фибоначчи с остатком при делении на m.

Формат выходных данных
Выведите длину повторяющейся последовательности, созданной на основе чисел Фибоначчи и остатка от деления m.

Примеры

Входные данные
4
2

Выходные данные
6
3
