Задача 5: Ближайшее красивое число
Ограничение по времени: 1 секунда

Под красивым числом будем понимать число, состоящее из одинаковых цифр. На вход программы подаётся произвольное целое число a. Необходимо найти ближайшее красивое число b такое, что b ≥ a. Например, для числа a = 1729 искомое число b = 2222.

Формат входных данных
В строке вводится целое число a (1 ≤ a ≤ 10^9).

Формат выходных данных
Выведите ближайшее красивое число, которое удовлетворяет условию задачи.

Примеры

Входные данные
1729
33

Выходные данные
2222
33
