Задача 1: Степень числа
Ограничение по времени: 1 секунда

Рассмотрим выражение 2^k ≤ a < 2^(k+1), где a — произвольное целое число, k — показатель степени числа 2. Для заданного числа a необходимо определить целое значение числа k, такое чтобы выполнялось рассмотренное выше условие.

Формат входных данных
В строке вводится целое число a (1 ≤ a ≤ 10^9).

Формат выходных данных
Выведите показатель степени k.

Примеры

Входные данные
5
10

Выходные данные
2
3
