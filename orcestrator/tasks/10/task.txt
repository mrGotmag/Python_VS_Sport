Задача 5: Почти красивое число
Ограничение по времени: 1 секунда

На вход программы подаётся целое число a. Необходимо найти минимально возможное целое число b, которое будет удовлетворять следующим условиям:
1) b ≥ a;
2) число b = b1b2...bn состоит из k ≥ n - 1 одинаковых цифр.
Например, для a = 1572 искомое число b = 1611.

Формат входных данных
В строке вводится целое число a (1 ≤ a ≤ 10^9).

Формат выходных данных
Выведите число b, удовлетворяющее условию задачи.

Примеры

Входные данные
1572
100

Выходные данные
1611
100
