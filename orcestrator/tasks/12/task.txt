Задача 2: Краткое ФИО
Ограничение по времени: 1 секунда

Для заданной фамилии, имени и отчества рассмотрим формирование краткого ФИО. Будем брать из фамилии, имени и отчества только первую букву, тем самым, образуя строку из трёх заглавных букв. Например, строка «Иванов Семён Петрович» будет преобразована на выходе к «ИСП». Очевидно, что люди с разными фамилиями, именами и отчествами могут иметь одинаковое краткое ФИО. Для заданного числа людей необходимо определить количество различных кратких ФИО.

Формат входных данных
В первой строке вводится количество студентов n (1 ≤ n ≤ 10^2). В следующих n строках вводятся фамилия, имя и отчество каждого студента.

Формат выходных данных
Выведите количество различных кратких ФИО.

Примеры

Входные данные
4
Иванов Семён Петрович
Ерофеев Егор Сергеевич
Игонин Сергей Олегович
Ивлев Сергей Петрович

Выходные данные
3

Входные данные
3
Петров Пётр Петрович
Павлов Павел Павлович
Сидоров Сидор Сидорович

Выходные данные
2
