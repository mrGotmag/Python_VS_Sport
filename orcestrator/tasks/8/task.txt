Задача 3: Компоненты связности в двоичном числе
Ограничение по времени: 1 секунда

На вход программы поступает целое число a. Рассмотрим его двоичное представление. Как известно, двоичная запись числа состоит из 0 и 1. Компонентой связности в двоичном числе будем называть подряд идущие единицы, которые отделены нулями от других единиц. Приведём пример. Пусть a = 22, тогда двоичная запись — это строка «10110». Здесь будет 2 компоненты связности из единиц. Первая компонента содержит 1 единицу, а вторая — две. Требуется написать программу, которая по двоичному представлению исходного числа определяет количество компонент связности из единиц.

Формат входных данных
В строке вводится целое число a в десятичной системе счисления (1 ≤ a ≤ 10^9).

Формат выходных данных
Выведите количество компонент связности двоичного представления исходного числа a.

Примеры

Входные данные
22
3

Выходные данные
2
1
